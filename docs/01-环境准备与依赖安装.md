# 第 1 章 环境准备与依赖安装

> 本文基于 **Orange Pi 5 Pro / Ubuntu 22.04 (aarch64)** 全流程实测。x86_64 的笔记本/台式机步骤完全相同。

## 1.1 硬件清单

| 硬件 | 要求 | 说明 |
|---|---|---|
| Linux 主机 | Ubuntu 20.04/22.04，x86_64 或 aarch64 | 树莓派/香橙派/旧笔记本均可 |
| USB 无线网卡 | **必须支持监听模式(monitor) + AP 模式** | 推荐 MT7612U、RTL8812AU、Atheros AR9271 |
| 显示器/串口/SSH | 远程运维 | 网卡切换模式时**机器自带网卡会断网**，务必走 SSH/有线 |

> ⚠️ **核心原则**：攻击用的 USB 网卡与联网网卡**必须分开**。本项目实测：USB 网卡 `wlx90de80defb54` 专门做监听/攻击，机器内置 `wlan0` 走 SSH 保证不掉线。

### 检查网卡能力

```bash
# 查看无线网卡列表
iw dev

# 查看网卡支持的接口模式（必须有 monitor + AP）
iw phy phy0 info | grep -A 20 "Supported interface modes"

# 检查驱动是否加载
lsmod | grep -E "mt76|8812|ath9k"
```

输出中应能看到 `monitor` 和 `AP` 字样。如果没有，说明网卡驱动不支持，需要换卡。

## 1.3 安装 Airgeddon

```bash
git clone --depth 1 https://github.com/v1s1t0r1sh3r3/airgeddon.git /opt/airgeddon
cd /opt/airgeddon
chmod +x airgeddon.sh

# 只做依赖检查（不启动交互界面）
sudo bash airgeddon.sh -c
```

首次运行交互式界面时会提示安装缺失依赖，按 `y` 自动装完即可。

> 本项目仓库的 `deploy/install-airgeddon.sh` 已封装以上全部步骤。

## 1.4 编译 hostapd-mana（假 AP 核心，关键步骤）

发行版自带的 `hostapd` **不支持** Evil Twin 所需的 `mana_wpaout`（开放模式抓明文握手）特性，必须从源码编译 [hostapd-mana](https://github.com/sensepost/hostapd-mana)。

```bash
# 编译依赖
sudo apt install -y build-essential pkg-config libssl-dev \
    libnl-3-dev libnl-genl-3-dev libnl-route-3-dev libpcap-dev

# 拉源码
git clone --depth 1 https://github.com/sensepost/hostapd-mana.git /opt/hostapd-mana
cd /opt/hostapd-mana/hostapd

# 配置并编译
cp defconfig .config 2>/dev/null || true
sed -i 's/#CONFIG_MANA/CONFIG_MANA/g' .config
make -j$(nproc)

# 安装（安装到独立名字避免覆盖系统 hostapd）
sudo install -m 755 hostapd /usr/local/sbin/hostapd-mana
```

### 验证 mana 特性

```bash
hostapd-mana -h 2>&1 | grep -i mana
# 应看到 mana_wpaout 等选项
```

> ⚠️ **实测坑**：市面上 hostapd-mana 有多个变体（fork）。本项目实测的二进制（sycophant 变体）**只支持 `mana_wpaout`**，不支持 `mana_wpa` / `mana_credout` / `mana_http_server`。因此本项目的假 AP 采用 **开放模式**（不设密码）+ DNS 劫持 + 钓鱼页收明文密码的方案，不依赖 mana 的 WPA 中间人特性。如果你编译的版本支持完整 mana 特性，可以进一步扩展。

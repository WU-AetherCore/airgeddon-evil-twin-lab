# 第 8 章 防御与法律合规

> 学攻击是为了防御。本章讲清普通用户和网络管理员如何抵御这类攻击，以及不可逾越的法律红线。

## 8.1 普通用户怎么防

| 措施 | 说明 |
|---|---|
| 核对 AP 是否为"开放/无锁" | 正常家庭 WiFi 都加密，看到**同名但无锁**的 WiFi 大概率是陷阱 |
| 核对路由器标签 | 自家路由器背面有 SSID/密码，对比确认 |
| 不连陌生开放 WiFi | 公共场合的开放 WiFi 都可能被劫持 |
| 敏感操作走加密连接 | HTTPS/VPN/SSH——即使 DNS 被劫持，传输内容仍加密 |
| 密码不要跨网复用 | 一个 WiFi 密码泄露不至于连带邮箱/银行 |
| 发现"同名 WiFi"立即警惕 | 有人在你附近架设假 AP，远离并报告 |
| 关闭 WiFi 自动连接 | 防止自动连上同名假 AP |

## 8.2 网络管理员怎么防

| 措施 | 原理 |
|---|---|
| 开启 WPA3-SAE | Dragonfly 握手更难被降级/伪造 |
| 关闭 WPS | 防 PIN 爆破 |
| 启用 802.11w (PMF) | 管理帧保护，**deauth 攻击基本失效** |
| 隐藏 SSID（作用有限） | 提高门槛，不防针对性攻击 |
| 部署 WIDS/WIPS | 无线入侵检测：识别同名 AP（Rogue AP）立即告警 |
| 企业级 802.1X | 每用户独立证书，钓鱼页无法冒充 |
| 定期审计 | 扫描周围同名/可疑 SSID |

### 一句话总结

**WPA3 + PMF 是当前最有效的家庭防御组合**——deauth 和假 AP 都很难得手。老旧设备只支持 WPA2 时，靠"用户教育 + 不连开放同名 WiFi"来兜底。

## 8.3 法律红线（重要）

在**中国大陆**，以下行为涉嫌违法：

- 《中华人民共和国网络安全法》第二十七条：
  > 任何个人和组织不得**提供专门用于侵入网络、干扰网络正常功能、破坏网络数据**的程序、工具……

- 《刑法》第二百八十五条 / 第二百八十六条：非法侵入计算机信息系统罪、破坏计算机信息系统罪

- 《治安管理处罚法》：干扰他人正常使用网络，可处行政拘留/罚款

**本项目仅限以下场景使用**：
1. 自己的路由器 / 自己拥有的 WiFi
2. 已获得明确书面授权的渗透测试（如企业委托的授权评估）
3. 学校/培训机构在**隔离实验环境**中的教学

**禁止**：
- 对邻居、公共场所、陌生人 WiFi 发起任何攻击（哪怕只是扫描探测）
- 将本项目用于窃取他人密码、蹭网、恶作剧
- 传播、出售本工具的改装版本用于非法用途

> ⚠️ 本项目开发者与贡献者不对任何非法使用承担法律责任。**每一次攻击都有痕迹，无线攻击尤其容易溯源（附近设备都能看到你的网卡在广播假 AP）。**

## 8.4 学习建议

1. 学完攻击再学防御，理解"对手怎么想"是安全从业者的基本功
2. 每次实验后**立即停止攻击、恢复网卡**（`restart_control.sh`）
3. 实验记录只保留在自己电脑，**不要上传任何真实捕获的密码/握手**
4. 想深入可继续学习：WPA3 降级攻击、PMKID 攻击、WIDS 绕过、802.1X 认证绕过
